# 배수정 홈페이지 (realcoach1.com)

KB손해보험 울산동구센터장 배수정 님의 보험상담·설계사 모집 홈페이지.
넷리파이에서 사용량 초과로 정지된 것을 되살리면서, 보안 문제를 고치고
관리자 수정이 실제 웹에 반영되도록 개조한 판입니다.

## 폴더에 무엇이 들어 있나

| 파일 | 하는 일 |
|---|---|
| `index.html` | 홈페이지 본체. 사진 8장이 파일 안에 들어 있어 1.9MB입니다 |
| `content.js` | 관리자가 「웹에 반영하기」로 고친 내용. **손으로 고치지 마세요** |
| `api/publish.js` | 고친 내용을 깃허브에 저장하는 서버 기능 |
| `api/notify.js` | 문의가 오면 텔레그램으로 알리는 서버 기능 |
| `vercel.json` | `content.js` 를 캐시하지 않도록 하는 설정 (없으면 반영이 늦게 보입니다) |
| `admin-guide.html` | 센터장님용 관리자 페이지 사용 안내서 |
| `og-image.jpg` | 카톡으로 공유할 때 뜨는 이미지 |
| `navere96….html` | 네이버 검색등록 확인용. **이름을 바꾸면 등록이 풀립니다** |

원본(개조 전) 파일은 `../realcoach-원본백업/` 에 있습니다. **옛 봇 토큰이 들어 있으므로
절대 깃허브에 올리지 마세요.**

## 무엇을 고쳤나

1. **텔레그램 봇 토큰 노출 제거** — 전에는 토큰이 `index.html` 안에 평문으로 있어서
   「소스 보기」로 누구나 가져갈 수 있었습니다. 알림을 `api/notify.js` 가 대신 보내도록
   바꾸고, 토큰은 버셀 환경변수로 옮겼습니다.
2. **관리자 수정의 웹 반영** — 전에는 고친 내용이 그 컴퓨터에만 남았습니다.
   이제 「🌐 웹에 반영하기」를 누르면 깃허브에 저장되고 버셀이 홈페이지를 새로 올립니다.
3. **화면에서 직접 고치기** — 전에는 이름·전화번호·사진 8장·후기만 고칠 수 있었습니다.
   이제 편집 모드를 켜면 **본문 글 175군데와 사진 전부**를 화면에서 눌러 고칩니다.
   입력칸을 175개 늘어놓는 대신 보이는 그대로 고치게 했습니다.
4. **넷리파이 전용 코드 제거** — 문의폼이 넷리파이 폼 기능에 물려 있어 버셀에서는
   동작하지 않았습니다. 걷어내고, 방치돼 있던 스팸 방지 덫(`bot-field`)을 실제로 쓰게 했습니다.
5. **자리표시자 정리** — 검색엔진에 알려주던 `여기에실제블로그주소` 같은 가짜 주소를 지웠습니다.

## 화면에서 직접 고치기가 동작하는 원리

고칠 곳마다 붙는 이름표는 **「태그 이름 + 원본 글자의 지문」**입니다 (`P-uinm3l` 같은 모양).
HTML 에 미리 적어 두지 않고 화면이 열릴 때 계산하므로, **1.9MB 짜리 index.html 을
건드리지 않아도 됩니다.** 지문이 원본 글자에서 나오기 때문에 순서가 바뀌어도 들어맞고,
나중에 원본 글을 손보면 지문이 달라져 옛 수정본이 **엉뚱한 자리에 붙지 않고 저절로 무시**됩니다.

- 프로필·강의사진·소식사진을 눌러 바꾸면 「사진 관리」 탭이 쓰던 자리(`photo`/`gallery`/`news`)에
  그대로 넣습니다. 두 화면이 어긋나지 않게 하기 위해서입니다.
- 그 밖의 사진은 `cmsImg` 에 담기고, 반영할 때 `media/cms_*.png` 파일로 올라갑니다.
- 붙여넣기는 서식을 걷어내고 글자만 남깁니다. 굵게·기울임·줄바꿈만 허용합니다.

## 배포 전에 반드시 할 일

> ⚠️ **옛 봇 토큰은 이미 8월 2일부터 인터넷에 공개돼 있었습니다.**
> 파일에서 지웠다고 해서 이미 새어 나간 것이 되돌아오지는 않습니다.
> 배수정 님이 텔레그램 BotFather 에서 **`/revoke` 로 토큰을 재발급**하셔야 합니다.
> 새 토큰은 **버셀에만** 넣고, 홈페이지 파일에는 절대 적지 마세요.

## 버셀에 넣어야 하는 값

Settings → Environment Variables. **값만 넣고 Redeploy 를 안 하면 적용되지 않습니다.**

| 이름 | 값 |
|---|---|
| `GITHUB_TOKEN` | 깃허브 fine-grained 토큰 (Only select repositories · Contents: Read and write · No expiration) |
| `GITHUB_REPO` | `계정명/저장소명` |
| `ADMIN_PIN` | 「웹에 반영하기」 비밀번호. **관리자 화면을 여는 번호와 다른 값으로 정하세요** |
| `TELEGRAM_TOKEN` | BotFather 에서 새로 받은 봇 토큰 |
| `TELEGRAM_CHAT` | 알림 받을 채팅 ID (관리자 페이지 → 문의 알림 → [채팅 ID 찾기]로 확인) |
| `ALLOWED_ORIGIN` | (선택) `https://www.realcoach1.com` — 남이 문의 알림을 퍼붓지 못하게 막습니다 |

## 비밀번호가 두 가지인 이유

- **관리자 화면을 여는 번호** — `index.html` 안에 적혀 있어 마음만 먹으면 볼 수 있는
  **초인종**일 뿐입니다. 이걸로는 진짜 홈페이지를 못 고칩니다.
- **`ADMIN_PIN`** — 「웹에 반영하기」를 누를 때 묻는 번호. 버셀 서버에만 있어
  홈페이지 파일을 뜯어봐도 알 수 없는 **진짜 잠금**입니다.
