배수정 홈페이지 · 관리자 페이지 사용 안내서

관리자 페이지는 홈페이지 안에 내장되어 있습니다. 별도 주소·파일이 아니라, 홈페이지 화면에서 바로 열립니다.

🔑 1. 관리자 페이지 여는 방법

1홈페이지를 열고 맨 아래(footer)까지 스크롤합니다.
2화면 맨 하단의 「· 관리자 ·」 작은 글씨를 클릭합니다.
3비밀번호 입력창이 뜨면 아래 번호를 입력하고 [확인]을 누릅니다.
●●●●
🔒 비밀번호는 보안을 위해 이 공개 안내서에는 표기하지 않았습니다. 별도 보관 중인 원본 안내서를 확인하세요.

🗂️ 2. 관리자 페이지에서 할 수 있는 것 (탭 5개)

👤 기본 정보이름·직함, 전화번호, 카카오톡, 이메일 등 연락처 정보를 수정합니다.
📷 사진 관리프로필 사진, 강의 현장 사진 4장, 이달의 소식 사진 3장을 새 사진으로 교체하고 설명을 답니다.
💬 후기 관리수강 후기를 수정·삭제하거나 [+ 후기 추가]로 새 후기를 올립니다.
🔔 문의 알림텔레그램 실시간 알림 연결을 확인합니다. 봇 토큰은 서버에만 보관되므로 이 화면에 넣지 않습니다. [채팅 ID 찾기]·[테스트 전송]으로 확인만 하시면 됩니다.
📊 방문 분석구글 애널리틱스(GA4)·네이버 애널리틱스 방문자 통계 연동(선택).

💾 3. 저장은 꼭 2단계 (중요)

1[변경사항 적용] — 방금 바꾼 내용을 지금 이 화면에 먼저 보여 줍니다. 아직 나에게만 보입니다.
2[🌐 웹에 반영하기] — 진짜 홈페이지에 올려 모든 방문자에게 보이게 합니다. 비밀번호를 한 번 더 물어봅니다.
⚠️ [변경사항 적용]만 하면 내 컴퓨터 화면에만 보입니다. 반드시 [🌐 웹에 반영하기]까지 눌러 주세요. 누른 뒤 30초쯤 기다렸다가 홈페이지를 새로고침(F5)하면 바뀐 내용이 나타납니다.
💡 예전에는 파일을 내려받아 직접 올려야 했지만 이제 그럴 필요가 없습니다. [HTML 파일로 저장]은 백업용으로만 남겨 두었습니다.

✅ 4. 현재 설정 상태 (참고)

• 문의가 접수되면 배수정 센터장님 텔레그램으로 자동 알림이 전송됩니다.
• 봇 토큰은 홈페이지 파일이 아니라 버셀(Vercel) 서버 안에만 보관됩니다.
• 관리자 비밀번호: 별도 보관 (공개 안내서 미표기)
🔐 비밀번호가 두 가지입니다. ① 관리자 화면을 여는 번호 ② [🌐 웹에 반영하기]를 누를 때 묻는 번호. ②번이 진짜 잠금이며, 홈페이지 파일을 아무리 뜯어봐도 알 수 없습니다.
